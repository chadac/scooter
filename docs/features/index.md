# Features

<!-- PITCH: hand-written framing goes here; each page below is the factual breakdown. -->

| Area | What you get |
|---|---|
| [Conversations & sandboxes](conversations.md) | One durable NixOS sandbox per conversation: suspend on idle, resume with state, workspace and installed tools intact |
| [Bring your own Claude](byoc.md) | Users serve their own conversations with their own Claude subscription from a container on their machine |
| [Models](models.md) | A provider-aware model catalog: per-provider offerings and defaults, agent-driven switching, per-conversation overrides |
| [Integrations](integrations.md) | Webhooks (GitHub/GitLab/Slack), scheduled runs, a permissions broker for cloud credentials, web-service proxying out of the sandbox |
